                         SECURITY LAYERS

    Layer 1: NETWORK
    ├─ UFW Firewall (host)
    ├─ Docker network isolation
    └─ Pouze caddy a portainer vystaveny ven

    Layer 2: APPLICATION
    ├─ HTTPS automatické (Let's Encrypt)
    ├─ Security headers (X-Frame-Options, CSP, etc.)
    ├─ JWT autentizace
    └─ Keycloak IAM

    Layer 3: DATA
    ├─ Encrypted connections (SSL/TLS)
    ├─ Hashed passwords
    ├─ Environment variables pro secrets
    └─ Regular backups

                    HEALTH CHECK SYSTEM

    ┌────────────────────────────────────────────────────────┐
    │                                                          │
    │  Každý kontejner má health check:                       │
    │                                                          │
    │  Backend:     GET /health → 200 OK                      │
    │  Frontend:    GET / → 200 OK                            │
    │  Postgres:    pg_isready → success                      │
    │  Keycloak:    GET /health/ready → 200 OK                │
    │                                                          │
    │  Při selhání:                                           │
    │  1. Health check fail (3x)                              │
    │  2. Container marked unhealthy                          │
    │  3. Automatic restart (restart: always)                 │
    │  4. Dependencies wait for healthy state                 │
    │                                                          │
    └────────────────────────────────────────────────────────┘

    Poznámka:
    • "-" znamená nepřístupné z venku (bezpečnější)
    • External = přístupné z host systému/internetu
    • Internal = pouze v Docker network

                    RESOURCE REQUIREMENTS

    Raspberry Pi 4 - Doporučeno:
    ────────────────────────────

    CPU:     4 cores @ 1.5GHz (ARM64)
    RAM:     4GB minimum, 8GB ideální
    Storage: 64GB+ (SD card nebo SSD)
    Network: 1Gbps Ethernet
    Cooling: Active cooling (fan)
    Power:   5V/3A+ official power supply

    Očekávané využití:
    ─────────────────

    RAM:     2-3 GB (7 kontejnerů)
    CPU:     20-40% za běžného provozu
    Disk:    ~5GB aplikace + data
    Temp:    50-65°C s aktivním chlazením
