═══════════════════════════════════════════════════════════════════
 🔐 KEYCLOAK ADMIN
═══════════════════════════════════════════════════════════════════

1. Přístup: http://IP:8080
2. Login: admin / KEYCLOAK_ADMIN_PASSWORD z .env
3. Vytvořit realm: "mineralogy"
4. Vytvořit client: "mineralogy-app"
   - Client Protocol: openid-connect
   - Access Type: confidential
   - Valid Redirect URIs: https://vase-domena.cz/*
5. Credentials tab -> zkopírovat Secret
6. Přidat do .env jako KEYCLOAK_CLIENT_SECRET
7. Restart backend
8. Vytvořit admin uživatele v Users

 🔥 FIREWALL (UFW)
═══════════════════════════════════════════════════════════════════

# Status
sudo ufw status verbose

# Povolit nový port
sudo ufw allow 8080/tcp

# Zablokovat port
sudo ufw deny 8080/tcp

# Smazat pravidlo
sudo ufw delete allow 8080/tcp

# Povolit z konkrétní IP
sudo ufw allow from 192.168.1.100 to any port 9443

# Reload
sudo ufw reload
